- lobe-icons 项目主页：https://github.com/lobehub/lobe-icons ；simple-icons：https://github.com/simple-icons/simple-icons
- 我们只做了去掉内联样式、固定宽高、把 `currentColor` 换成 #1d1d1f（telegram 用 #26A5E4），图形本身未改。
- 开源许可只覆盖 SVG 文件。这些图形对应的商标归各自所有者，本站仅用来标识商品，与这些公司没有任何关联。
- Muse 没有找到可确认对应的 logo，Midjourney 在数据库中没有对应商品，所以没有使用；没有 logo 的商品显示首字母方块。
